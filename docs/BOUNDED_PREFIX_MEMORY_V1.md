# Bounded lawful-prefix memory v1

Review profile: DUAL_REVIEW. Evidence class: PUBLIC_REPOSITORY_ONLY. This additive
numeric reference preserves admitted observations; it implements no consumer, predictor,
loader, physical qualification or empirical gate. Existing Projection, lifecycle, area
contracts and studies remain unchanged. Full-prefix preservation is not task sufficiency
or evidence for the primary appearance-robustness hypothesis.

`BoundedPrefixMemory(source, access, trust, availability, episode, source_head)` uses the
actual validated `CausalInput` and existing external `Trust`. Access must be the exact
frozen typed ecological set: SURFACE_REGIONS, REGION_CORRESPONDENCE, EXECUTED_ACTION.
Denial precedes prefix inspection/serialization or relation extraction. Privileged
generation records and mixed permissions are rejected.

The admitted domain is exactly three complete consecutive images at indices 0, 1, 2,
one fixed positive shape with at most 1024 pixels, and at most 16 observed-ever nodes.
These are characterization caps, not a training allocation or general A2 horizon.
Longer/shorter prefixes, skipped/missing images and false completeness/association/identity
trust flags are rejected. A complete image with zero visible regions is valid; it is not
a missing image. Existing CausalInput validation owns/revalidates observations and exact
executed/announced numerical commands. No general state or missing-data framework is added.

`feature_bytes()` returns canonical JSON with only:

- `shape`;
- three `frames`, each with its `index`, aligned Boolean `masks`, `observed` flags and
  optional `contacts`;
- the two genuinely executed command triples and announced query triple, in exact reduced
  rational strings rather than rounded floats.

Each frame's `observed` flag means sampled visible presence in that complete image. It is
not prefix-known status. Prefix-known eligibility, first/last observation times and the
last observed support follow from the complete three-frame presence/mask history. Every
decision-time observed-ever node has a row in every frame; absence has zero support.
Before a node's first observation, zero rows mean not-yet-observed, distinguishable through
chronology, not a hidden inventory claim.

Three exact Boolean availability flags control relation endpoints only. An unavailable
endpoint has `{available: false, pairs: null}` and is not extracted. Available endpoints
have unordered distinct row-index pairs from four-neighbour visible image contact;
`pairs: []` means available with no such contacts. Contacts are not occlusion order,
ownership, flow or geometric cause. Masks are always complete, regardless of relation
availability. All masks and relationships are already lawful prefix observations.

`alignment` maps row indices to episode-opaque keys outside features. Joint key permutation
permutes masks/presence and both contact endpoints together; token spelling carries no
predictive information. No IDs, episode, source hash, binding, raw roles, camera pose,
coordinates, depth, generation record, hidden inventory, future target or evaluator cause
is included in the numerical block.

`binding_bytes()` separately binds version `bounded-prefix-memory-v1`, episode/source-head
identity, exact complete input digest, feature digest, alignment, decision index 2, target
index 3 and announced query. Supplied source-head identity is syntactically validated and
bound; this in-memory interface does not inspect a checkout to authenticate it. Features
and binding are immutable owned bytes. `revalidate()` validates the owned complete prefix
and caps; it does not independently rederive feature/binding consistency. Constructor
extraction establishes that correspondence. `storage()` reports logical serialized byte
lengths of numeric block, retained prefix and binding, not RSS or runtime latency.

Both prospective ecological and generic consumers must receive the identical history,
action and contact availability through lossless equivalent encodings. No consumer is
implemented. A later restricted-history or compressed last-seen summary is an information
ablation, not an equal-information principal baseline. Original A2 remembered-target,
NEW/FOV/unknown qualification and learned identity questions remain separate; nothing here
asserts that observed absence is complete occlusion.

`python scripts/check_bounded_prefix_memory_source.py` runs only public handwritten fixture
tests with native/model/collector/producer/audit imports denied. Synthetic smoke validation
revalidates the prefix, reconstructs identical features and prints logical storage/hash
information. No private physical pair geometry or outcomes are fixtures or public evidence.
No real generation, fitting, held-out efficacy, Gate0D, gate advancement or biology claim
follows from passing these checks.
