# Causal oracle-region lifecycle v1

Review profile: `DUAL_REVIEW`; evidence class: `PUBLIC_REPOSITORY_ONLY`. This developmental original 0C subset implements chronological region bookkeeping and neutral completed-label reconstruction. It is not the final EPS state, same-face persistence, sensory identity, a forecast, or an adopted benchmark. No native adapter, producer, model, experiment or gate authority is added.

`epsbench.diagnostics.causal_region_lifecycle` reuses `VisibleRaster`, existing `Action` and typed modality permissions. `advance` requires exactly `SURFACE_REGIONS`, `REGION_CORRESPONDENCE`, `EXECUTED_ACTION`; it rejects denied permission and future access before asking the provider for an observation. The supplied decision index declares the lawful observation cutoff; this API does not prove historical wall-clock chronology. Skipped/repeated indices and missing/invalid executed actions reject before fetch. Initialization is index zero with no predecessor action; every later update appends one validated executed action.

The provider returns a typed `TrustedObservation`: a complete visible raster and explicit `complete_image`, `complete_association`, `stable_identity` assertions. These must literally be true, and there must be no unresolved support. The adapter must establish all image cells observed, background zero semantics, complete visible-label/token bijection, stable episode/geometry-unit association and token nonreuse. Raster schema validation alone does not establish those facts. Assertions are trusted adapter obligations, not independent qualification or credentials. This module implements no real-world adapter. A provider may report missing/ambiguous association with a null raster and unresolved visible-label/pixel counts; unknown counts are null.

Identity kind is `ORACLE_REGION_UNIT`: one oracle-associated geometry unit, potentially with disconnected visible pieces or different physical faces. Local segmentation labels can change; random opaque episode tokens persist. No hidden catalogue enters the state. Missing/ambiguous association or incomplete/malformed observation produces an atomic `Update` with the exact unchanged prior state and an `Unresolved` record. It creates no new token or invented empty mask and emits no completed labels. All known inventory nodes are excluded for that rejected transition. The next index cannot silently skip the missing observation. Provider exceptions propagate without mutating prior state; callers must retain such failures, not reinterpret them as absence or authorize automatic retries.

Admitted state has the observed-ever token union, current and immediately preceding Boolean masks, first/last visible indices and `VISIBLE`/`REMEMBERED_ABSENT` status. Never-observed hidden units are excluded with unknown cardinality. Empty support means raster nonvisibility under a complete observation, not occlusion, destruction, frame exit or hidden extent. Nodes are never pruned. Initial predecessor masks are null; newly observed nodes in a later complete frame have empty predecessor support. Remembered nodes keep their observation indices. Immutable mask bytes and validated canonical Action bytes snapshot inputs.

State at `t` uses observations/associations through `t` and actions executed through `t-1`. An announced next action is outside state and supplies no future information. Future masks, transport, correspondence/events, complete two-frame transition loaders, evaluator target designation, metric/raw simulator data, hidden inventory, generation records and source/configuration metadata are excluded from features. Provenance and unresolved records remain separate. After observation `t+1` arrives, the new state can reconstruct the completed transition; those labels were not predictions made at `t`.

`reconstruct` enumerates the complete selected inventory `I_(t+1)`. From predecessor set B and current set A it derives `b=|B|`, `a=|A|`, overlap `|B intersect A|`, gained `|A minus B|`, lost `|B minus A|`. It emits existing `VisibilityState`, `RegionCorrespondence` and `RegionMaskChange` schemas. Fractions divide by positive common image area `H*W`, using the same Python binary64 division as existing `derive_visibility`; inventory coverage divides by token count, not image area. Empty inventory is `NOT_APPLICABLE`. Never-observed units and unselected causal/graph labels remain explicitly omitted.

Existing precedence is unchanged: zero-to-positive emits only `REGION_APPEARED` with gained count; positive-to-zero only `REGION_DISAPPEARED` with lost count. Otherwise emit gained then lost independently when nonzero; if neither, emit `MASK_UNCHANGED` with zero count, including remembered both-zero masks. Same-image-coordinate overlap is not material-point transport. The test/reference checker derives sets directly from original trusted rasters and implements this precedence independently; it does not call converter classification or use reconstructed labels as truth. Renaming and lossless serialization are fidelity controls, not efficacy baselines.

Canonical bytes use existing `utils.canonical.canonical_json_bytes`: sorted object keys, compact `,`/`:` separators, UTF-8 with unescaped Unicode, `allow_nan=False`, Python finite float JSON round-trip spelling, no BOM or trailing newline. Executed actions are revalidated by the existing closed strict `Action` schema and normalized via `model_dump(mode="json")` before encoding; full log count equals decision index. Current Action scope remains positive forward or signed lateral, with zero yaw; no new action class is introduced. Decoder requires exact decode/re-encode byte equality, rejecting duplicate keys and alternate JSON spellings, unknown keys, invalid actions and command counts. Nodes are token-sorted; masks are row-major MSB-first packed bits, zero final padding, standard canonical base64. Decode validates mask lengths, padding, chronology/status/index invariants and nonoverlap.

At a noninitial index, logical masks occupy `2*N*ceil(H*W/8)` bytes before base64/JSON. `storage()` reports mask payload, command payload, node count and actual canonical serialized length, including the node metadata and full command history. It does not claim interpreter RSS or transactional peak: callers must also charge arrays, integer intermediates, temporary serialization, old/new states, snapshots and retained history. Each update preserves the prior current mask as predecessor; the older predecessor can be released after the next completed result is retained. Two masks per node and growing inventory/commands are not demonstrated compact EPS.

The guarded source check runs only public software fixtures, including deterministic serialization, validation and readable inspection. No renderer, SDK, model or private evidence is permitted. Original 0B/0C/0E remain incomplete; useful before-only predictive state/task/readout, full graph/causal labels and qualified surface identity remain missing. Gate 0D authority is absent and the charter hypothesis remains UNTESTED. Historical failures, recovery 18/21, Slice 6 FAILED_CLOSED, held48 and parked helpers are preserved.
