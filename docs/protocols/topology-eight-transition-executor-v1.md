# Eight-transition executor implementation

Review profile: `DUAL_REVIEW`. Evidence class: `PUBLIC_REPOSITORY_ONLY`.
Phase-gate effect: `NONE`. Implementation and guarded CPU verification are
authorised; actual capture remains separately held. This document adds no
benchmark acceptance rule or renderer contract.

The immutable [v1 protocol](topology-eight-transition-v1.md) and its byte-identical
membership remain the scientific design. The separate executor implements only
that finite schedule: eight transitions/contexts and 48 native render/read pairs.
It reuses unchanged single-occluder generation, canonical paired capture,
typed loaders, topology derivation and independent reconstruction. The historical
32-context qualification command remains outside this study.

`scripts/topology_eight_transition.py plan` is inert: it prints the prospective
source/configuration/protocol/membership binding without a namespace or graphics.
The sole execution operation is `capture --root <exact-wsl-path>
--human-preflight <completed-receipt>`. Do not invoke it under implementation
authority. It requires a real PR and exact executable head in the independently
completed human receipt, target-machine receipt, review/CPU evidence references,
explicit owner capture decision and exact native/WSL C-drive namespace. Programs
verify byte bindings; they do not evaluate or manufacture review/owner decisions.
Pydantic schemas reject unknown and missing fields. All fields remain unresolved
until the later human/machine preflight; no runnable receipt is supplied here.

The script refuses existing study roots or supervisor receipts. The internal
worker requires its live script supervisor and applies kernel address-space and
CPU-affinity limits before NumPy/graphics imports. Initial context preparation
requires both OSMesa environment variables and pins `LIBGL_ALWAYS_SOFTWARE=1`,
`GALLIUM_DRIVER=llvmpipe`. The actual counted context must report llvmpipe; other
software renderers are rejected before draws. There is no environment/backend
fallback, preflight context, resume, retry, replacement, extension or search.
Source and installed-runtime byte bindings are checked before each cell and after
its saved-data assessment. Completed cell artifacts and ledger prefix are checked
before the next reservation. A constructor attempt is reserved before invocation;
wrong-order or excess native calls are rejected before the native function.

Successful cells require saved native reconstruction, complete unchanged dataset
validation, public topology reconstruction, privileged correspondence assessment,
artifact inventory and cleanup. A cell terminal precedes lock release; a separate
durability barrier fsyncs saved producer/assessment files and directories from
deepest to root before the terminal. Unsupported or failed fsync stops permanently.
release revision must return successfully before advancement. Every exception
stops the live invocation, including errors after unlink or visible publication.
Failure receipts are attempted independently of the ledger, with supervisor logs
retained outside the namespace. Failed locks are closed without unlinking; no
already-released lock is recreated. Historical non-atomic ownership races remain
unresolved and the controlled-writer scope is unchanged.

Public derivation accepts exactly ecological typed inputs. Privileged camera,
depth, raw IDs and generation records are used only in the separate privileged
assessment. Standalone topology is never retrofitted into dataset capabilities.
Every support count/component/event is retained. Valid negative or indeterminate
outcomes complete the remaining controls; exact repeat/appearance and explicit
reversal comparisons report disagreements without outcome-dependent retries.
Inspections use saved arrays only. Runtime/path/time records are operational;
deterministic comparison excludes exactly dataset `run.json` and retains its bytes
in inventories separately. This implementation establishes no empirical result.

The resource supervisor confines descendants and threads to two logical CPUs and
sets inherited 8 GiB address-space limits. It monitors aggregate RSS, new output,
five-minute cell and 45-minute invocation deadlines at 100 ms intervals, kills the
owned process tree on breach, and preserves outputs/locks. Watchdog sampling has
finite detection latency: aggregate RSS/output monitoring is not a hard cgroup or
filesystem quota guarantee. Actual target capacity, enforcement suitability,
headroom and operator resource agreement must be resolved before capture; these
CPU tests do not qualify TPUQMNG or demonstrate an actual Linux containment run.
If the exact protocol limits cannot be enforced on that runtime, capture must not
start. No remote access/dispatch is assumed.

Guarded CPU tests use synthetic arrays, fake SDK/native functions and mocked
process/resource interfaces. They cannot provide executed native study evidence.
Real rendering smoke and WSL target preflight are held. New exact-head independent
engineering/scientific reviews are required. A public push/PR, inherited renderer
CI, WGL routing, capture, merge, closeout and empirical gate remain separate
authorities. Historical reviews, studies and hash-bound documents are untouched.
