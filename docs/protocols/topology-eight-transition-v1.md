## 1. Question and limits

Does the fixed existing single-occluder crossing yield an eligible-transport
supported background split and the exact reverse its corresponding merge,
consistently across two legacy appearances and identical repeats?

112 continuations and no split/merge. Existing closed-form fixtures establish
algorithmic semantics, not rendered positive coverage. This finite study tests
that gap. It cannot qualify frozen Slice 6, complete Gate 0B, qualify WGL,
establish ideal geometric ownership, metric accuracy, ordinary-RGB alignment,
predictive EPS superiority or biological claims. Legacy remains the default;
frozen Slice 6 remains `FAILED_CLOSED`. No Gate 0C/0D, merge, closeout, default,
benchmark/renderer-contract change or model authority is granted.

## 8. Integrity lifecycle and permanent stop

One coordinator/writer controls the live output root. Initialisation records the
prospective plan once; reserve a cell before any constructor. The executable
protocol must bind order, verified prefix, empty cell paths, source/runtime,
native budgets and human preflight receipt before each reservation. Existing
O_EXCL ownership checks remain non-atomic against an arbitrary directory mutator;
no platform-hardening or stronger adversarial claim is part of this package.

On success publish immutable evidence and a successful cell terminal only after
all validations and flushes, then release the acquired lock under the unchanged
primitive. A separate immutable release-confirmation revision must follow
successful release before the next cell is eligible. A terminal without that
confirmation is a stopped/uncertain prefix, even if the lock path is absent.
This handles post-unlink fsync/publication errors conservatively without
recreating a lock over a foreign path or claiming rollback durability.

Capture, provenance, reconstruction, permission, budget, source/runtime drift,
publication, cleanup, timeout/resource or release errors permanently stop the
namespace. Retain the actual lock path and all available outputs; close descriptors
without unlinking on pre-release failures. After irreversible release, preserve
the absent/foreign-path observation and unconfirmed prefix; do not fabricate lock
retention. Save failure information when publication remains possible; if it fails,
retain outer logs and treat missing terminal/confirmation as stopped. No next-cell
operation can accept an orphan, retained lock, unconfirmed release or failed tail.

No retry, resume of an uncertain/interrupted attempt, replacement namespace,
extension, reset, auto-clear, tuning, seed search or changed masks/rules is included.
Successful confirmed cells permit only the next not-yet-reserved ordinal, subject
to fresh source/runtime/prefix checks. Stop after ordinal 7 and saved-data
assessment. Lost contact is not evidence of termination: inspect existing state
read-only and require operator confirmation; never relaunch blindly.
