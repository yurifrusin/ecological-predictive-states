# Known-region image-area diagnostic v1

Additive, model-free development software, implementing the reviewed per-target proposal.
This does not replace EPS-Bench, qualify a physical adapter, authorize collection/training,
advance Gate 0D or establish task usefulness/appearance robustness.

## Input and target

Exact typed ecological permissions are revalidated before candidate parsing/provider access.
Use complete genuine episode-start observations 0/1, nonempty known inventory, both observed
relation endpoints and complete external association/history assertions. Every queried action
has identical history, lifecycle, shape, inventory, episode and source provenance; only the
announced action differs. Executed and announced whole commands must be pure lateral.
Commands are reduced exact rationals; duplicate numeric actions are rejected even with different
names. This domain restriction is not inferred physical static-scene qualification.

For each known node i and common action a, y_ia is future observed mask cardinality divided by
H*W. It is normalized image-plane area, not solid-angle integration, physical surface fraction or newly disclosed area. Complete
trusted absence gives zero, including remembered nodes. Never-observed NEW is a separate
neutral evaluator-only area, excluded from target inventory, prediction and utility.
No future-responsive target selection is allowed: all prefix-known nodes count equally.

`save(projection, rows)` binds complete rational q_ia in [0,1] to the exact input/action; sum_i q_ia
must be <=1. Floats use exact IEEE fractions. `validate` requires canonical bytes, unique exact
inventory and reduced rational strings. `evaluate(projections, arms, providers)` freezes the
collections and detached prefix/bindings/statuses, validates every arm/action before any future
fetch, then obtains exactly one trusted observation at index2 per action. All scorers share
those retained targets. Any incomplete/invalid arm, future or qualification rejects the whole
operation, without a favorable partial score. Trust flags are external adapter assertions,
not proof of geometry/lineage. There is no filesystem, native producer, model or controller.

## Six before-only controls

All whole-command checks precede shortcuts. Let c_i,p_i be current/previous areas, e executed
lateral command and a announced lateral command.

- zero:0; persistence:c_i; replay:p_i.
- linear_trend: e=0 uses c_i; otherwise clip(c_i+(a/e)(c_i-p_i),0,1). If total>1,
  divide every value by that total, before outcomes.
- centroid_transport: a=0 or e=0 uses c_i. Otherwise shift each CURRENT mask by (a/e)
  times observed centroid displacement, each axis rounded nearest with half ties away from
  zero, and discard off-image pixels. Either endpoint empty falls back to c_i, including
  remembered current-zero. Transport cannot increase current cardinality; overlapping
  transported supports need no normalization of these area forecasts.
- history_lookup: a=0 uses current masks; otherwise exact a=-e uses previous masks;
  other actions use centroid_transport. It consults only supplied two-frame history.

Opaque token spelling/provenance are alignment/binding context, never control features.
Existing lossless structured/unstructured Projection codecs provide identical lawful feature
information, but no learned E/U implementation is admitted here.

## Scores and independent target selectors

Actions sort by numeric rational (forward,lateral,yaw), with the first maximizer breaking exact
prediction ties. For EACH node independently choose ahat_i=argmax_a q_ia. Different targets can
choose different actions: no simultaneous execution/achievement is claimed. Report all-node
L=mean_a,i (q_ia-y_ia)^2, MAE and signed bias; realized R_i=max_a y_ia-y_i,ahat_i and
Rbar=mean_i R_i. Also report visible/remembered strata (empty strata null), per-target regrets,
predicted/optimal ties, realized action contrasts, and selection-only fixed-first/fixed-last
mean regrets. Report indices refer to the canonical numeric action order; node rows remain
prefix alignment, never a learned spelling feature. Fixed references have no forecast MSE.

Finite realized bound: Rbar<=min(1,2 sqrt(|A|L)). Software checks Rbar^2<=4|A|L and Rbar<=1,
and reports the squared upper bound exactly. If mu_ia is conditional expected area under the
same before-history and fixed action set, uniform max_i,a |q_ia-mu_ia|<=epsilon gives expected
mean opportunity regret<=2epsilon. Average MSE alone does not give that uniform guarantee;
realized and conditional-expected oracle regrets differ. No practical margin/population/power
claim follows from exploratory directional score comparison or handwritten software checks.

## Retention and inspection

An immutable Evaluation retains canonical input/action binding hashes, every candidate hash,
observed future integer raster/association and recomputable report. `inspect` takes typed
permissions plus original projections/arms and these retained bytes, reconstructs trusted
retained observations locally and requires exact replay equality. It never fetches a physical
future. A hash/replay proves consistency, not independent physical truth; retained qualification
is the original external assertion, not rediscovered evidence. Any byte/binding/report change
rejects inspection. No partial result is returned after future rejection.

Source guard blocks native/reference/producer/collector/model imports and loads only handwritten
focused tests, including fake smoke/validation/inspection. Scoped Linux/Windows CI excludes
native qualification/full-suite jobs on this branch. Past Q/O/V are exposed development examples;
PR77 stays closed INCONCLUSIVE and all old studies/gates remain unchanged.

Existing typed Action requires nonzero lateral displacement; zero executed/announced fallbacks above are defensive formulas currently unreachable through a valid Projection. This package does not widen that action contract.
