# Restricted mask projection v1

`DUAL_REVIEW` / `PUBLIC_REPOSITORY_ONLY`. This native-free adapter implements only the adopted route-v2 common feature projection and binding to the unchanged neutral mask target. It implements no network, model stub, trainer, producer, collector, study or qualified task signal. Status IMPLEMENTED_PENDING_REVIEW; phase-gate effect NONE.

`restricted_mask_projection.Projection` requires a genuine complete consecutive `CausalInput` from index zero, the accepted PR67 `State`, exact typed lifecycle permissions, explicit `Trust` assertions, two endpoint availability flags, a decision cutoff, opaque episode/source bindings and a genuine announced `Action`. Permissions reject before caller serialization/parsing; future prefixes/states reject before observation access. Two completed observations are required: initialization is outside this route's domain. Shape, inventory, full executed chronology, remembered/first-seen history and masks must agree.

The supplied complete prefix is evaluator/binding context, not features. `Trust` asserts complete history/image/association and stable oracle REGION identity; these literal true values are external adapter obligations, not facts inferred from validation. No actual qualification adapter is implemented. Given those assertions, `lifecycle` reconstructs through existing `advance` from the same supplied visible masks, with deterministic local relabeling, then compares exact canonical lifecycle bytes. It does not fabricate older observations, shift time or truncate remembered inventory. All historical input storage is charged even though features use only recent masks.

Genuine executed Action bytes come from the supplied lifecycle, preserving their validated names and metadata. Exact `Fraction(binary64 component)` triples must equal the original prefix commands. The announced Action is checked the same way and its canonical metadata is kept in the binding. A rational such as `1/3` cannot match an Action binary64 value and rejects; no epsilon or rounding is introduced. Valid signed zero has rational value zero in numeric features, while original signed-zero Action spelling remains in lifecycle/binding context. Unsupported zero/mixed/yaw commands reject under the existing Action schema, without widening its domain.

`feature_bytes()` is the ONE shared P_t for any later structured/flattened reader. It contains node current/preceding Boolean masks, signed integer difference, visible/remembered status, relative first/last-seen ages, preceding and announced exact rational command strings, both endpoints' sampled adjacency/availability/relative age, and identically derived current/preceding occupied unions. Node positions align through a separate opaque tuple; pair records use those numeric positions. Tokens are never numeric embeddings. Features contain no raw labels, geometry, depth, pose, optical cause, full command history, absolute indices, episode/source hashes or unselected boundary attributes. No reader-specific feature subset is implemented.

Available adjacency is derived through `BoundaryObservationView` from the SAME before-only supplied masks and opaque visible association. Non-background differing lattice neighbours create undirected sampled shared-boundary pairs, uniquely sorted; background boundaries supply no node pair. This is not causal ownership, containment, whole-object adjacency or future occlusion. No caller boundary records are accepted. Endpoint age is one/zero. An unavailable endpoint carries `pairs=null`, an available endpoint with no positives carries `pairs=[]`; unavailable does not become a negative edge. Availability itself remains an explicit external assertion and must be qualified later.

`feature_bytes(True)` is ONLY the previous-mask ablation: removes each preceding mask/difference and the preceding occupied union. It retains observed-ever channel alignment, current masks/union/status, first/last-seen ages, both endpoint adjacency/availability/time, preceding command and announced command. Those fields retain historical information; this is not current-only or a test of general history necessity. All consumers receive the same ablated bytes if that arm is later admitted.

Features, full prefix, lifecycle and bindings are immutable owned bytes; masks are detached immutable snapshots, and permissions are copied. `revalidate` reconstructs and compares all projection/context snapshots before saving or evaluating. Alignment and episode/source/index/action/prefix/lifecycle/feature hashes live in separate binding bytes. Renaming opaque tokens permutes node/pair alignment equivariantly; sorted token spelling changes positions but conveys no learned numerical token value. Source/episode bindings do not prove physical identity.

`save(known,new)` constructs the EXISTING neutral `Candidate` with precisely every prefix-known channel plus anonymous NEW, preserving disjoint-mask and whole-channel UNKNOWN rules, and wraps its canonical bytes with the projection-binding digest. It supplies no predictive readout. `persistence()` copies current known masks and empty NEW solely for software-contract checks. Missing relation observations remain explicit inputs; this adapter does not infer sensory truth or choose a learned abstention policy.

`evaluate(saved,provider)` validates permissions, complete context/projection, exact wrapper binding, strict canonical spelling/closed keys and existing candidate inventory/action/index/shape before exactly one evaluator-only `t+1` fetch. It delegates all semantic target construction, neutral labels, N/U/C/E denominators, ignorance bounds and loss to unchanged `neutral_observation_target.evaluate`. No target/loss reimplementation exists. An empty inventory still scores NEW; UNKNOWN never becomes success. The provider must independently establish complete target image, stable association, same episode and announced action execution; an index check alone cannot prove these facts. Source call order is not durable acquisition chronology.

Canonical bytes reuse repository sorted-key compact UTF-8 JSON, finite number spelling, no BOM/trailing newline. Stored numeric command strings are reduced exact rationals. `storage()` charges features, alignment, binding, full prefix and lifecycle context separately; it does not claim interpreter RSS, copy/serialization peak, model memory or compactness. Future candidate/evidence and all retained snapshots cost additional storage.
