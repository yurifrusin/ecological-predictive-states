# Fraction extrapolation v1

`DUAL_REVIEW` / `PUBLIC_REPOSITORY_ONLY`. One parameter-free, untrained scalar rule and paired persistence baseline use accepted PR67 oracle REGION lifecycle state and an announced validated Action. This is a prospective source contract, not empirical capability, a learned model, a mask generator or full EPS. Existing mask-valued contracts and lifecycle formats are unchanged.

For each observed-ever token in the complete `I_t`, let `a` be current support count divided by positive image area `H*W` and `b` immediately previous support count divided by that same area. At `t >= 1`, with complete trusted consecutive history, the last executed and next announced actions must both have zero forward/yaw and nonzero signed lateral components `d` and `q`. Extrapolation is `clip(a + (q/d)*(a-b), 0, 1)`; persistence is `a`. Count fractions, exact binary64 action values, ratio and clipping use `Fraction`. Each clipped prediction and persistence value is rounded once by Python's supported Fraction-to-float conversion to binary64 nearest, ties-to-even. No epsilon or fitted coefficient is introduced, and extreme ratios cannot overflow the rational intermediate. Canonical JSON uses repository finite float round-trip spelling. No intermediate higher precision prediction is scored.

Both rules have identical eligibility and exactly the full `I_t`. Initialization, incomplete asserted history or a valid forward command gives explicit paired UNKNOWN, retained with ordered reasons. Existing Action validation rejects malformed/nonfinite/zero lateral/yaw commands rather than treating malformed data as UNKNOWN. A first-seen node's legitimate empty predecessor mask participates; remembered nodes with zero current and previous support predict zero when eligible and count later misses. Empty inventory is not applicable. UNKNOWN coverage cannot supply an apparently complete favorable score. Independent fractions may sum above one; evaluation reports that limitation without renormalizing or inventing masks.

`Input` snapshots/revalidates the immutable lifecycle and canonical announced Action bytes after checking exact typed lifecycle permissions (`SURFACE_REGIONS`, `REGION_CORRESPONDENCE`, `EXECUTED_ACTION`). Its cutoff forbids a future before-state. Episode key, source head, lifecycle digest, action digest, before/target indices, shape and oracle identity kind bind the separate forecast envelope; they are excluded from `feature_bytes()`. Readout uses no contour labels, ownership, transport, metric coordinates, depth, pose, raw IDs, hidden inventory or future targets. The opaque episode/source metadata do not select the rule.

Save the complete paired forecast as immutable canonical bytes before evaluator-only access. `decode(saved, input)` checks closed keys, typed canonical unique token records, eligibility, finite binary64 fractions, exact complete inventory, context/action/index binding and exact equality to the before-only rule, plus canonical decode/re-encode bytes. Duplicate JSON keys, alternative spellings, missing tokens and partial UNKNOWN are rejected. `evaluate` completes that validation before calling the provider once at `t+1`. This source ordering is not durable historical sealing or protection from arbitrary caller forgery; an empirical operation still needs separately admitted chronology evidence.

The narrow evaluator receives a `TargetEvidence` raster and matching external binding, with explicit complete-image, complete-association, stable-identity and announced-action-executed assertions. The adapter must certify same episode/unit, complete coverage and consecutive accepted observations; a validated State, typed record or assertion flag cannot establish physical qualification. No actual adapter is implemented. Missing, contradictory, incomplete or incorrectly indexed/shaped evidence is unresolved with no score. Provider exceptions propagate and must be retained by the caller. Missing known tokens become zero only after all these checks.

Evaluation independently traverses original next-raster samples to count support for every old `I_t` token. Newly visible tokens remain outside prediction scope: only their aggregate count/pixel support is reported, never their identities to the rule. Scores use exact rational values of the saved decoded binary64 predictions against exact target counts/`H*W`. Reports retain KNOWN, CURRENT_VISIBLE and REMEMBERED_ABSENT token denominators and coverage; per-rule MAE and extrapolation-minus-persistence difference are absent for empty/unsupported groups. They also report changed-known-token count, mean absolute known support change, aggregate new support, and both predicted sums. Current visibility strata come from the before-state, not future selection.

These are per-action descriptive reports. The adopted later primary unit is a prospectively declared geometry/common-prefix/two-action fork, averaging both actions and all declared `I_t` tokens without retrospective exclusions. This source package selects no geometries, membership, criterion or outcomes and implements no runner. Strata and target change are explanatory, not a way to select a favorable primary denominator. Full serialization charges all retained prediction/binding metadata; source state, target records, transaction copies and interpreter memory are separate caller costs. No resource-performance claim is made.

Focused public software tests cover rational values/signs/ratios/clipping, extreme ratio and rounding, shared UNKNOWN, first/remembered/new tokens, coherence, pre-target validation and independent target counts/errors/strata, malformed records, rename invariance and canonical round-trip. The guarded checker blocks native/model/producer imports and prints deterministic synthetic validation/inspection. These are source fixtures, not scientific samples or guarantees of future success. Nonlinear projection, occlusion and sampling can defeat this heuristic.
